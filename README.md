# suivi-annualisation

Application de suivi des 1607 heures, plannings et congés, réservée aux collaborateurs (accès protégé par identifiant/mot de passe).

## Installer l'application sur mobile (PWA)

L'application est une **Progressive Web App** : elle s'installe comme une vraie app sur l'écran d'accueil, en plein écran, sans passer par l'App Store ou le Play Store. L'accès reste privé : seules les personnes disposant d'un identifiant créé par l'administrateur peuvent se connecter.

### iPhone (Safari)
1. Ouvrir le lien de l'application dans **Safari** (obligatoire, pas Chrome).
2. Appuyer sur l'icône **Partager** (carré avec flèche vers le haut).
3. Choisir **Sur l'écran d'accueil**.
4. Valider. L'icône apparaît sur l'écran d'accueil et l'app s'ouvre en plein écran.

### Android (Chrome)
1. Ouvrir le lien de l'application dans **Chrome**.
2. Appuyer sur le menu **⋮** (trois points).
3. Choisir **Installer l'application** (ou **Ajouter à l'écran d'accueil**).
4. Valider.

Une fois installée, l'app se comporte comme une application native : icône dédiée, plein écran, et fonctionnement hors-ligne partiel pour la coquille de l'app (l'accès aux données nécessite toujours une connexion).
