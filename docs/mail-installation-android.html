📱 Suivi Annualisation
Installez l'application sur votre téléphone Android

Bonjour à toutes et à tous,

Une application mobile vient d'être créée pour votre planning : compteur d'heures, calendrier du mois, congés et demandes d'absence, le tout pensé pour le téléphone. Ce n'est pas le site habituel : l'affichage a été entièrement repensé pour être utilisable d'une seule main.

L'installation prend moins de deux minutes.

⬇️ Télécharger l'application
Lien à ouvrir depuis votre téléphone Android
🤖 Sur Android — étape par étape
1. Ouvrez ce mail depuis votre téléphone, puis appuyez sur le bouton bleu ci-dessus.
2. Le téléchargement démarre. Un message peut demander de confirmer : appuyez sur « Télécharger quand même ».
3. Une fois terminé, appuyez sur le fichier annualisation.apk (notification de téléchargement, ou dossier Téléchargements).
4. Android affiche : « Pour votre sécurité, votre téléphone n'est pas autorisé à installer des applications inconnues provenant de cette source ».
→ Appuyez sur Paramètres, puis activez « Autoriser depuis cette source », puis revenez en arrière.
C'est normal : cette application est réservée au magasin et n'est donc pas publiée sur le Play Store.
5. Appuyez sur Installer, puis sur Ouvrir.
6. Connectez-vous avec vos identifiants habituels. L'icône « Annualisation » est maintenant sur votre écran d'accueil.
🍏 Vous avez un iPhone ?
Pas d'application à installer : ouvrez annualisation.pages.dev dans Safari, appuyez sur l'icône Partager (le carré avec une flèche), puis sur « Sur l'écran d'accueil ». Le résultat est identique.
